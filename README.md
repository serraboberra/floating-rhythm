# Floating Rhythm

**Your body knows the way.**

Floating Rhythm is a living practice calendar built around a 16-animal day/night cycle. It brings movement, rhythm, recovery, meals, work, notes, and everyday life into one flexible structure rather than forcing practice into a rigid schedule.

## Movement practices

Floating Rhythm treats four movement traditions as first-class practices:

- **Qi Gong**
- **BaGua Zhang**
- **Hsing-I**
- **Tai Chi Chuan**

Qi Gong, BaGua Zhang, and Hsing-I use animal-specific movement records organized as:

> **Starting Position → Exact Movement Sequence → Ending Position → Next Movement Begins Here**

Tai Chi Chuan uses Yin/Yang short-form posture libraries selected by the day's animal. Each posture records stance, feet and weight, arm positions, hand shape/orientation, body alignment, gaze, and distinctive quality while leaving transitions open for personal authorship.

## The 16-animal cycle

The prototype expands from the traditional Five Animals anchor:

**Tiger · Wood → Deer · Water → Bear · Earth → Monkey · Fire → Crane · Metal**

The larger 16-animal sequence is arranged around complementary animal-to-animal movement relationships, so each animal relates to both the animal before it and the animal after it.

The evolving cycle also preserves key relationships including:

- **Owl → Unicorn → Rooster**
- **Dragon → Shark → Snake → Mantis**

Owl and Shark retain their distinct authored form identities.

## Prototype

The current prototype is a standalone `index.html` site. No build system is required for the single-file version.

### Run locally

Download or clone the repository and open `index.html` in a modern web browser.

### Publish with GitHub Pages

This repository can be published as a static site with GitHub Pages. The repository's `index.html` serves as the site entry point.

## Design principles

- **Living rhythm rather than rigid scheduling**
- **Animal-specific movement rather than generic fallback exercises**
- **Day/night variation within one coherent cycle**
- **Movement practices remain distinct while sharing a common rhythm**
- **Transitions in Tai Chi remain available for personal authorship**
- **New revisions build cumulatively on the latest complete prototype**

## Project status

Floating Rhythm is an evolving personal practice prototype. The current version establishes the interactive foundation and the four-practice movement architecture, including Hsing-I as a full part of the system.
